## Оценка в Google Colab

Откройте `04_evaluate.ipynb`, включите GPU в настройках среды выполнения и запустите ячейки по порядку. Загрузите командный `project_data.zip` или исходный `test.jsonl`. Блокнот проверяет SHA-256 разбиения и по умолчанию оценивает baseline и опубликованный адаптер B42. Добавьте путь до [адаптера B123](results/B123/README.md) или своего адаптера в `ADAPTERS`, чтобы сравнить его с baseline в тех же условиях.

## Оценка из терминала

Команды выполняются из корня общего репозитория. Используйте отдельное окружение с CUDA-сборкой PyTorch для вашей видеокарты и установите зависимости из `requirements.txt`. Параметр `--data` принимает оригинальный архив, исходный `test.jsonl` или папку с разбиениями.

```sh
python -m pip install -r requirements.txt
python evaluate.py --data project_data.zip --output runs/evaluation --adapter B42=results/B42/adapter --adapter B123=results/B123/adapter
```

При запуске без `--adapter` проверяется только baseline. `--split validation` запускает техническую проверку на первых 30 задачах validation с теми же правилами. Итоговый режим `--split test` оценивает все 200 задач. Для повторного запуска укажите новую папку для результатов.

Модель получает условие задачи и общую инструкцию. Оценка использует один исходный checkpoint, шаблон Qwen ChatML, жадное декодирование, батч 8 и до 192 новых токенов. `protocol.py` принимает единственную финальную строку `#### число` и сравнивает число с эталоном. Любая ошибка формата входит в знаменатель accuracy. Если генерация достигла лимита, но последняя строка пригодна для разбора, она оценивается по общему правилу.

В `metrics.csv` accuracy хранится долей от 0 до 1, а `delta_pp` — в процентных пунктах относительно baseline из того же прогона. `metrics.json` сохраняет версии библиотек, устройство, ревизию модели, параметры генерации и хеши входов. В `*.predictions.jsonl` доступны ответ, извлечённое число и результат сравнения по каждой задаче.

## Повтор B123

`train_b123.py` вызывает общий `train.py` с Teacher B и seed 123. Он сверяет 1 000 опубликованных промптов Teacher B с train и готовит 150 примеров validation. Для B123 используются тот же исходный checkpoint, LoRA rank 8, alpha 16, две эпохи, шаг `2e-4`, эффективный батч 16 и ограничение 512 токенов.

```sh
python train_b123.py --data project_data.zip --output-dir runs/B123/full
```

Обученный адаптер, настройки, входные хеши и логи находятся в `runs/B123/full/`. В комплекте сдачи эта папка лежит под `personal/B123/`. Чтобы оценить её после распаковки, передайте `--adapter B123=personal/B123/adapter`.

Для повтора в Colab выполните ячейки установки зависимостей и загрузки командного кода из `04_evaluate.ipynb`. Загрузите `train_b123.py` и полный `project_data.zip` в папку `PROJECT`, затем выполните команду обучения из этой папки.
